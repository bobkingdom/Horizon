## [445-Byte JavaScript ASCII World Map via Deflate-Raw](https://simonwillison.net/2026/Jul/4/building-a-world-map-with-only-500-bytes/#atom-everything) ⭐️ 7.0/10

Iwo Kadziela created a 445-byte JavaScript demo that renders a detailed ASCII world map by fetching a base64 data URI, piping it through DecompressionStream with deflate-raw, and inserting the result into the DOM. The technique showcases extreme minimalism in web development by leveraging built-in compression APIs and data URIs to deliver surprisingly rich visual output from tiny payloads. The code uses fetch on a data: URI, DecompressionStream('deflate-raw'), and Response.text() to decompress and display the map without any external files or large scripts.

rss · Simon Willison · Jul 4, 23:09

**Background**: DecompressionStream is a Web API that decompresses streams using formats such as deflate-raw, while data URIs allow embedding compressed content directly in JavaScript without separate network requests.

## [LoRA Adapter Gates Tool Use via Internal Confidence in Qwen3.5-4B](https://www.reddit.com/r/MachineLearning/comments/1unw5un/competence_gate_gating_tooluse_on_a_small_models/) ⭐️ 7.0/10

A 10MB LoRA adapter was released for Qwen3.5-4B that gates tool use (direct answer, web search, or local RAG) based on internal activations rather than verbalized confidence, with d′ improvement of 0.46 and reduced private query leakage from 22% to 10%. It runs locally via MLX on Apple Silicon and GGUF for llama.cpp/Ollama, with open weights under Apache-2.0. This approach improves error detection and privacy for small local LLMs by reading internal signals directly, enabling better refusal to hallucinate and routing sensitive queries locally instead of to public search. The adapter shows 87% of flagged errors were genuine mistakes; it fails to improve grounded QA on SQuAD 2.0 as parametric competence signals differ from evidential grounding; GGUF matches MLX decisions at --lora-scaled 8 with 0.83 agreement.

## [Dartmouth AI Tutor Claims Large Effect Sizes Amid Method Skepticism](https://intextbooks.science.uu.nl/workshop2026/files/itb26_s1s2.pdf) ⭐️ 6.0/10

A Dartmouth study reports an AI tutor delivered effect sizes of 0.71-1.30 standard deviations in a course. The system uses Claude Sonnet for grading constructed-response questions against rubrics, yet only about 16 students reached full engagement. Such reported gains could influence adoption of AI tools in education, yet doubts about methodology may slow acceptance among instructors and institutions seeking reliable evidence. Results stem from statistical modeling of engagement and midterm scores rather than randomized trials, and the platform functions mainly as an AI-graded quiz system with optional RAG chat.

hackernews · jonahbard · Jul 5, 18:47 · [Discussion](https://news.ycombinator.com/item?id=48796817)

**Discussion**: Commenters question the small fully-engaged sample size of roughly 16 students, absence of randomization, and potential Hawthorne effect from novelty. Many argue the system is primarily a quiz platform with AI autograding rather than a genuine interactive tutor.

## [Proposal: Semantic Compression as Diffusion for Long LLM Sessions](https://www.reddit.com/r/MachineLearning/comments/1un63hv/proposal_use_semantic_compression_as_input/) ⭐️ 6.0/10

A Reddit proposal introduces a diffusion-inspired method that applies staged semantic compression to let LLMs process sessions exceeding their context window by starting with coarse outlines and progressively refining to verbatim details. This approach targets preservation of non-local holistic information that retrieval and standard compaction often lose, potentially improving coherence in extended AI sessions without requiring larger context windows. Each slice fits the context window; the model receives the current compression level, prior output, and input, with basic tests on Qwen2.5 7B showing partial success but unreliable end-to-end results; the repo is at https://github.com/dev-boz/diffusive-semantic-compression.
